# Icon source

The mini-program UI icon font comes from the official Iconfont.cn project
[2275070](https://at.alicdn.com/t/project/2275070/db4d5200-5c79-42ad-a58c-579ddc701fc9.html),
font build `ut3kprmb8f`.

The WOFF2 is embedded in `styles/iconfont.scss` to avoid a runtime download
domain dependency. Tab-bar PNGs are rendered from the same official font.
